# Horizon Wallpaper

Fonds d'écran animés pour Windows, légers et élégants, par **HorizonStudio**.

**[Télécharger la dernière version](https://github.com/Atlantic669/horizon-wallpaper-releases/releases/latest)**, puis lancez `HorizonWallpaper-Setup-x.y.z.exe`.

Ce dépôt ne contient que les installeurs. L'application se met à jour toute seule.

- [Confidentialité](PRIVACY.md) : ce que l'application enregistre et les seules connexions qu'elle fait. Il n'y a aucune télémétrie.
- Une question ou un problème ? [Ouvrez une discussion](https://github.com/Atlantic669/horizon-wallpaper-releases/issues).
